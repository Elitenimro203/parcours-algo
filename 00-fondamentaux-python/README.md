# Fondamentaux Python — mécanismes transverses

Dossier transverse (comme `00-patterns-entretien/`) pour les mécanismes du
langage Python rencontrés au fil du programme — pas liés à un algorithme en
particulier, mais utiles partout.

**Convention :** un mécanisme = un fichier `.md`, nommé sobrement d'après le
mécanisme (ex. `name-main.md`, `decorateurs.md`, `generateurs.md`...).

## Sommaire
- [`name-main.md`](./name-main.md) — `if __name__ == "__main__":`, `=` vs `==`
- [`pytest-bases.md`](./pytest-bases.md) — convention de nommage, structure d'un test, `assert`
