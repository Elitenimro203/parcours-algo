# Révisions espacées

Contre l'oubli : quand on attaque la programmation dynamique, le tri par
sélection ne doit pas être à moitié oublié.

## Format
Sessions courtes (5-10 min), PAS une session complète refaite :
- Réexpliquer le principe à voix haute/à l'écrit, sans relire le code
- Réécrire le pseudo-code de tête
- Un seul cas limite à identifier sans aide

## Cadence suggérée
- J+3, J+7, J+21 après avoir terminé un module (répétition espacée classique)
- Sinon : au minimum, 5 min de révision d'un ancien module au début de chaque
  nouvelle session de travail sur ce programme
